ZVG Email Templates — Ready to Copy into Business Central
==========================================================

These files contain the EMAIL BODY TEXT for each document type.
Copy the text into a Custom Report Layout (Word) or use as a guide
when creating Word Templates in BC.

Folder structure:
  EN/  = English templates
  DE/  = German templates

How to use (quick steps):
  1. Search in BC: Custom Report Layouts
  2. New → Copy (e.g. Sales Order - Default Email Body)
  3. Export Layout → open in Word → paste text from these files
  4. Add merge fields from XML Mapping Pane (Customer Name, Document No., etc.)
  5. Import Layout back to BC
  6. Search: Report Selection - Sales (or Purchase)
  7. Set Email Body Layout Description = your new layout name

See Email-Templates-Setup-Guide.md for full step-by-step instructions.
